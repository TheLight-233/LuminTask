# 运行时架构与约束

[English](architecture.md)

1. **任务身份与所有权**。`LuminTask` 是任务值、Builder 和 Awaiter。同步成功的句柄为 0。挂起任务由全局非泛型 `LuminTaskSource` 管理，每页 32 个托管槽，最多同时租用 32,767 个槽。48 位代际区分槽位复用前后的身份。
2. **结果存储**。最多 16 B 且不含引用的值使用槽内联区，引用由 GC 跟踪。较大或含托管引用的结构体使用强类型单元。运行时使用 `ref` 与 `Unsafe`，关闭 C# unsafe，禁止原生导入和原生分配依赖。
3. **发布顺序**。先写终态，再唤醒等待方。在槽、页与缓存锁外执行续体和调用方回调。迟到的生产者不能修改复用后的槽。
4. **预热成本与驻留**。编译器状态机首次挂起时租用 Runner。默认 64 KiB 空闲对象与类型索引预算。活动槽和调度数组单独计量。`Trim()` 释放当前空闲的槽页、缓存和调度缓冲。
5. **依赖边界**。Core 独立于 AsyncEx 和 Unity。Unity 适配拥有引擎对象、监听和 PlayerLoop 调度。改变取消、销毁或解绑顺序时，覆盖重入、迟到回调和任务槽归还。
6. **性能回归**。固定业务调用、运行时、构建设置与负载，对比操作分配、延迟、驻留、GC 次数或时长以及 AOT 产物尺寸。扩容和增加泛型特化都要提供数据。
